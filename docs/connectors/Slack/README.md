# The Slack Connector

The [Slack Connector](https://claude.ai/directory/connectors/slack) grants access to read and write Slack messages, and to view Slack user info.

## Access

No special setup required; just add the connector then sign in with your Slack account, granting the app permissions.
If prompted for our workspace id, we're `clearchanneluk.slack.com` (yes, still Clear Channel, and UK regardless of your actual country; there's tech debt to be tidied).
