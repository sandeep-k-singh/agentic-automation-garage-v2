# The Atlassian Rovo Connector

The [Atlassian Rovo](https://claude.ai/directory/connectors/atlassian) Connector grants access to various Atlassian Cloud solutions:

- Jira
- Confluence
- (Compass)

## Access

No special setup required; just add the connector then sign in with your Atlassian account.
If you have access to multiple instances of a system under the same account you'll be asked to select which instance to use.
